# Social Tools

Various scrappers you can use on your personal social sites.
Only designed to work with your local token.

Anything you can see on your account can be downloaded.

Tools are designed to scope downloads to safe limits, not site wide scrapes.


#Install Python Poetry Environment (2.0 version)
```
touch pyproject.toml
pyenv install 3.12.7
pyenv global 3.12.7
poetry install
poetry env activate
source .venv/bin/activate
```
